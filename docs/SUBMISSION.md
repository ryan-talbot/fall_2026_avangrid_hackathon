# Submission guide

The submission consists of the PowerPoint and this GitHub repository. The
organizer scores the presentation, so it includes the model explanation,
results, assumptions and proposed utility action.

## Code and evidence

The repository contains the Python analysis, fixed experiment configurations,
README, dependency files, verification checks and aggregate figures. Follow
[RUNBOOK.md](RUNBOOK.md) for installation and local data setup. The final
acceptance command validates input hashes, model evidence and packaging.

The organizer specifies no GitHub repository naming convention. The existing
repository URL can be submitted directly.

## Presentation

The organizer's filename pattern is
`team number_team name_Final Submission.pptx`. Use the assigned team number
and registered team name, then upload through the organizer's SharePoint folder.

The completed presentation uses 12 main slides and 11 evidence appendix slides.
Its local package is documented in [Presentation](../deck/PRESENTATION.md).
Household examples remain in the authorized submission package because they
contain customer-level information. Public aggregate figures are in `deck/`.

## Interpretation

The shared battery's $9,250 installed-cost advantage applies to the historical
15% showcase and assumed prices. Customer screening supports outreach and
confirmation. The proposed pilot requires site engineering, comparable quotes
and testing on future peak days.
